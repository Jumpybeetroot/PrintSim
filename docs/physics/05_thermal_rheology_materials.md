## 1. Governing Equations, Dimensional Checks & Assumptions

### 1.1 Heatbreak conduction ([hotend.py:L179-183](file:///Users/jumpybeetroot/Projects/printsim/src/printsim/thermal/hotend.py#L179-L183))

$$A_{hb} = \pi\left(r_o^2 - r_i^2\right),\quad r_o = r_i + t_w,\qquad R_{hb} = \frac{L_{hb}}{k_{hb}A_{hb}}\;\left[\frac{\text{m}}{\text{W m}^{-1}\text{K}^{-1}\,\text{m}^2} = \text{K/W}\right]$$

Hand check on the default Ti-6Al-4V part (ID 2 mm, wall 0.25 mm, L 12 mm): $A = 1.767\ \text{mm}^2$ and $R = 1013.5\ \text{K/W}$. The code returns 1013.5 K/W. ✅

### 1.2 Cold-side energy balance ([hotend.py:L186-190](file:///Users/jumpybeetroot/Projects/printsim/src/printsim/thermal/hotend.py#L186-L190))

$$\dot Q_{hb} = \frac{T_h - T_\infty}{R_{hb}+R_{hs}},\qquad T_{cold} = T_\infty + \left(\dot Q_{hb} + \dot Q_{par}\right)R_{hs},\qquad \dot Q_{par} = 0.016\,(T_h - T_\infty)$$

This is a series resistance network with one cold node. Units are W and K. The parasitic term (radiation and convection from the block into the heatsink) is a lumped 0.016 W/K conductance with no citation. For the defaults it dominates the heat leak: $\dot Q_{par} \approx 3.0$ W against $\dot Q_{hb}\approx 0.19$ W. The creep criterion is $T_{cold} > T_g - 6\,^\circ\text{C}$.

### 1.3 1-D axial finite-volume profile ([hotend.py:L59-159](file:///Users/jumpybeetroot/Projects/printsim/src/printsim/thermal/hotend.py#L59-L159))

Steady fin equation, discretised on $n=40$ uniform nodes:

$$\frac{d}{dz}\!\left(kA\,\frac{dT}{dz}\right) - g_{amb}'(T - T_\infty) = 0
\;\Rightarrow\; \sum_{nb} G_{i,nb}(T_i - T_{nb}) + g_{amb,i}(T_i - T_\infty) = S_i,\qquad G_{i,i+1} = \frac{(kA)_{i+1/2}}{\Delta z}$$

The heater block is held at temperature by a penalty Dirichlet condition ($G_{pen}=10^4$ W/K). The heatsink is a uniform distribution of $1/R_{hs}$. The source term $S$ is radiative injection into the first two heatsink nodes. Units are W/K for every conductance. ✅

**Patankar (1980, §4.2.3)** states that the face conductance between two cells in series must be the *harmonic* mean, $(kA)_{i+1/2} = 2(kA)_i(kA)_{i+1}/[(kA)_i+(kA)_{i+1}]$. The code uses the arithmetic mean (see the findings table).

### 1.4 Transient heat-up ([hotend.py:L207-228](file:///Users/jumpybeetroot/Projects/printsim/src/printsim/thermal/hotend.py#L207-L228))

$$C\frac{dT}{dt} = P_{in}(t) - \left(\frac{1}{R_{hb}+R_{hs}} + h A_{blk}\right)(T - T_\infty),\qquad C = m_{blk}c_{blk} + m_{noz}c_{noz} + 2.5\ \text{J/K}$$

The integrator is explicit Euler with $\Delta t = 0.25$ s. For the default (Cu block, 14 g) $C\approx 9.8$ J/K and $G\approx 0.033$ W/K, so $\tau = C/G\approx 300$ s. The stability limit is $\Delta t < 2\tau$. ✅
PLA heats up in 27.8 s on a 70 W heater, which matches a lumped estimate of $C\,\Delta T/P\approx 26$ s. ✅ After reaching temperature the controller is P-only with an 8 K band, which leaves a steady offset of about $8\,P_{loss}/P_{max}\approx 0.8$ K.

### 1.5 Bed heat-up ([hotend.py:L230-243](file:///Users/jumpybeetroot/Projects/printsim/src/printsim/thermal/hotend.py#L230-L243))

$C_{bed}\dot T = P - h A (T - T_\infty)$, with $h = 14$ W m⁻² K⁻¹ (natural convection plus radiation from the top face only) and $C_{bed} = m_{plate}c_{plate}$.

### 1.6 Heater-power-limited flow ([hotend.py:L246-250](file:///Users/jumpybeetroot/Projects/printsim/src/printsim/thermal/hotend.py#L246-L250))

$$e_v = \rho\left[c_p (T_p - T_\infty) + L_f\right]\ [\text{J/mm}^3],\qquad Q_{pow} = \frac{0.88\,P_{htr} - \dot Q_{loss}}{e_v}$$

Units: $\text{kg/m}^3 \times 10^{-9}\ \text{m}^3/\text{mm}^3 \times \text{J/kg} = \text{J/mm}^3$. For PLA, $e_v = 0.48$ J/mm³, which matches the code comment. ✅

### 1.7 Melt-zone conduction limit (reference model vs. code)

**Physically based reference: Graetz/Lévêque plug-flow heating.** The governing energy balance for a heated bore at constant wall temperature $T_w$ is:

$$\rho c_p \bar u \frac{\pi D^2}{4}\frac{dT_m}{dz} = h\pi D (T_w - T_m),\quad Nu = \frac{hD}{k} = 3.66
\;\Rightarrow\; \theta_{exit} = \frac{T_w - T_{m,exit}}{T_w - T_{in}} = \exp\!\left(-\frac{\pi\,Nu\,\alpha\,L}{Q}\right)$$

Solving for the flow gives

$$\boxed{Q_{melt} = \frac{\pi\,Nu\,\alpha\,L}{\ln(1/\theta_{req})}},\qquad \alpha = \frac{k}{\rho c_p}$$

This result does not depend on bore diameter. It depends linearly on $L$ and on the polymer's $\alpha$. It *increases* with $T_w$, because $\theta_{req} = (T_w - T_{extrudable})/(T_w - T_\infty)$ grows. For PLA ($k\approx0.18$, $\alpha\approx 8\times10^{-8}$ m²/s, $L=18$ mm) it gives $Q\approx 7$–$10$ mm³/s for full melting. Real hotends (V6 ≈ 15, Volcano ≈ 25–30 mm³/s) exceed this because the polymer only needs to be extrudable, not fully melted, and the core can stay partly unmelted (Go et al., *Addit. Manuf.* 16 (2017); Mackay, *J. Rheol.* 62 (2018)).

**What the code computes** ([hotend.py:L252-259](file:///Users/jumpybeetroot/Projects/printsim/src/printsim/thermal/hotend.py#L252-L259)) is an empirical fit, not a Graetz solution:
$$Q_{melt} = 1.48\,L_{mm}\,\left(\tfrac{k_{eff,metal}}{115}\right)^{0.28}\left(\tfrac{d_n}{0.4}\right)^{0.45}\left(\tfrac{0.48}{e_v}\right)^{0.35}$$
The 1.48 mm³ s⁻¹ mm⁻¹ slope reproduces V6/Volcano data well. Its temperature and material dependence are wrong (see the findings table).

### 1.8 Nozzle pressure drop and push force (reference model vs. code)

**Reference: power-law fluid with the Rabinowitsch correction.** The viscosity law is $\eta = K\dot\gamma^{n-1}$. For each cylindrical segment:

$$\dot\gamma_a = \frac{4Q}{\pi R^3},\quad \dot\gamma_w = \dot\gamma_a\,\frac{3n+1}{4n},\quad \tau_w = K\dot\gamma_w^{\,n},\quad \Delta P = \frac{2L\tau_w}{R}
\;\Longleftrightarrow\; Q = \frac{\pi n R^3}{3n+1}\left(\frac{R\,\Delta P}{2KL}\right)^{1/n}$$

For the convergent cone, the lubrication approximation gives $\Delta P_{cone} = \frac{2K}{3n\tan\beta}\left(\frac{(3n+1)Q}{\pi n}\right)^{n}\left(R_2^{-3n}-R_1^{-3n}\right)$ (Bellini 2004; Osswald et al., *Int. Polym. Proc.* 33 (2018)). Temperature enters through an Arrhenius or WLF shift $a_T$ on $K$. The push force is $F = \Delta P_{tot}\,\pi d_f^2/4$.
Check: PLA with $K = 6000$ Pa·sⁿ and $n = 0.36$ at 20 mm³/s through an 18 mm × Ø2 mm chamber plus a 0.8 mm × Ø0.4 mm orifice gives ΔP = 1.79 MPa, so F ≈ 4.3 N. Measured forces are 20–40 N. The difference is the unmelted-core and entry (Bagley) losses, which is why the pressure limit and the melt limit are coupled.

**What the code computes** ([hotend.py:L262-265](file:///Users/jumpybeetroot/Projects/printsim/src/printsim/thermal/hotend.py#L262-L265)):
$Q_{press} = 1.55\,P_{max}[\text{MPa}]\,\phi^{-1/(2.2n)}\,(d_n/0.4)^{2.2}$, with $P_{max} = F_{max}/A_f$ (N/mm² = MPa ✅). This is linear in pressure. The comment above it claims $Q\propto P^{1/n} d^{3+1/n}$, which the code does not implement. No ΔP(Q), Rabinowitsch correction or push-force calculation exists.

### 1.9 Part cooling ([hotend.py:L279-281](file:///Users/jumpybeetroot/Projects/printsim/src/printsim/thermal/hotend.py#L279-L281))

$\theta_{max} = \text{clip}(42 + 18\ln(1 + 0.55\,\text{CFM}/c_d),\ 38,\ 78)$ and sag $= 1.45/(1 + 0.38\,\text{CFM}/c_d)$. Both are purely heuristic, with no Newtonian cooling, Biot or Nusselt basis.

### 1.10 Structural catalog formulas ([profiles.py](file:///Users/jumpybeetroot/Projects/printsim/src/printsim/schema/profiles.py))

- Hollow square tube (Bredt–Batho): $J = \dfrac{4A_m^2 t}{\oint ds/t} = \dfrac{4(b-t)^4 t}{4(b-t)} = (b-t)^3 t$ ✅. $I = (b^4 - b_i^4)/12$ ✅. Corner radii are neglected.
- Rectangle (Roark Table 10.7, full dimensions): $J = ab^3\left[\tfrac13 - 0.21\tfrac ba\left(1 - \tfrac{b^4}{12a^4}\right)\right]$. This is within 0.2 % of the exact Saint-Venant series for MGN9, MGN12 and MGN15 ✅.
- Round rod: $I = \pi r^4/4$ and $J = \pi r^4/2$ ✅.
- Isotropic shear modulus: $G = E/[2(1+\nu)]$ ([materials.py:L45-49](file:///Users/jumpybeetroot/Projects/printsim/src/printsim/schema/materials.py#L45-L49)) ✅.
- Mahieux–Reifsnider (2002) single-transition form: $E(T)/E_{25} = \dfrac{(1-e_r)\exp[-(T_K/T_{ref})^m] + e_r}{(\cdot)|_{25^\circ C}}$, with temperatures in K ✅. At $T_g$ the code gives $E/E_{25}\approx0.39$ for ABS. The $T_{ref}$ shift, $0.32\max(0, HDT - T_g - 80)$, is an uncited fit.

### 1.11 Belt & stepper ([printer.py:L490-L648](file:///Users/jumpybeetroot/Projects/printsim/src/printsim/schema/printer.py#L490-L648))

- Transverse string mode: $f = \dfrac{1}{2L}\sqrt{T/\mu}$. The code matches the analytic value exactly (155.42 Hz at 25 N, 150 mm) ✅. Axial span stiffness is $k = EA/L$.
- Hybrid stepper: $T(\theta) = -T_h\sin(p\theta)$, so $k_\theta = pT_h$ with $p = N_{steps}/4$ (50 rotor teeth for a 1.8° motor) ✅. Electrical frequency is $\omega_e = p\,\omega_m$ ✅. Copper loss is $P = 2I_{rms}^2R$ for two phases ✅.

## 3. Recommended Ground-Truth Tests (to add in `tests/`)

1. **FVM conduction benchmark:** Set convection to zero, apply Dirichlet conditions at both ends of a 3-material rod, and require $R_{eff} = \sum L_i/(k_iA_i)$ within 1 %. This fails today (−15 %).
2. **Melt flow monotonicity:** $Q_{melt}(T_p+20) > Q_{melt}(T_p)$, and $Q_{melt}\propto L$. The first fails today.
3. **Rabinowitsch pipe:** Once implemented, ΔP(Q) must match the closed-form power-law pipe solution, and doubling $F$ must scale $Q$ by $2^{1/n}$ in the nozzle-dominated limit.
4. **Profile sanity:** For `shape="extrusion"`, require J/(I_y+I_z) < 0.15. For tubes, require Bredt J within 2 % of the thin-wall formula.
5. **Stepper:** `effective_holding_torque_nm` must have slope 1 at small current and equal T_h at rated current.
6. **Belt:** 110 Hz at 150 mm must give 8.9 ± 0.5 N for GT2-6 fiberglass.
